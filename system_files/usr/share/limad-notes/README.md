# LiNotes 1.0.0-preview2

Native GTK4-Notizen-App für LiMaD OS. Notizen werden automatisch in einer lokalen SQLite-Datenbank gespeichert. Anhänge liegen als normale Dateien unter `~/.local/share/limad-notes/attachments` und werden von LiSave gesichert.

Enthalten sind Ordner, Schnellnotizen, angepinnte Notizen, Suche, Listen- und Galerieansicht, automatische Speicherung, Papierkorb, Dateianhänge, Import aus TXT/Markdown/HTML/RTF/ENEX, Export als TXT/Markdown/HTML, Markdown-basierte Formatierungswerkzeuge, iCloud-Notizen-Zugriff in Zen sowie LiLink-Handoff.

Eine native Zwei-Wege-Synchronisation mit der proprietären Apple-Notizen-Datenbank ist nicht enthalten. Apple Notizen wird offiziell über iCloud im Zen Browser geöffnet.
