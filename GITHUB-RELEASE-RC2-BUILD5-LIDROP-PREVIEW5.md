# LiMaD OS 2.8.0 RC2 Build 5 – Intel-Mac-, Notebook- und PC-Edition

## Neu in diesem Paket

### LiDrop 0.12.0-preview5

- zwei LiMaD-OS-Rechner mit einem sechsstelligen Code verbinden
- Kopplung wird automatisch in beide Richtungen eingerichtet
- Rechner im lokalen Netzwerk über Avahi suchen
- mehrere Dateien direkt von System zu System senden
- Übertragungsfortschritt und Fehlerstatus in LiDrop anzeigen
- Empfang automatisch unter `Downloads/LiDrop`
- SHA-256-Prüfung nach dem Transfer
- Smartphone- und Browserübertragung bleibt erhalten
