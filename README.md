# LiMaD OS 3.0

Ubuntu 26.04 LTS / GNOME 50 build starter for LiMaD OS 3.0.

German build and migration documentation: [README-DE.md](README-DE.md) and [docs/BUILD-LIST-DE.md](docs/BUILD-LIST-DE.md).


## Default GitHub repository

The Linux and macOS starters default to `bushcraftjw-glitch/limad-os`. Authentication is persisted through GitHub CLI (`gh auth`), and existing remote `main` history is preserved before pushing updates.
